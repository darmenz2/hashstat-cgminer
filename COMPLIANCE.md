This document describes the source published in this repository. It is not a license declaration for components or binaries distributed elsewhere.

## Licenses and attribution

The GNU GPLv3 text is in [LICENSE](LICENSE) and [core/COPYING](core/COPYING). HashStat files marked `GPL-3.0-only` use that license. Third-party files retain their original notices and license terms; the repository-level license does not replace them.

[NOTICE](NOTICE) records the cgminer base revision and the Mujina-derived components. Preserve these attributions, the original copyright headers, and the license texts when redistributing or modifying the source.

## Source and binary releases

`source-lock.json` records the inputs used by the core build tools. Keep the manifest consistent with the published source. It verifies those inputs; it is not a certification that a separate firmware binary corresponds to this tree.

For a binary release, identify the exact source revision, local modifications, build configuration, and toolchain versions. Provide the complete Corresponding Source and any required Installation Information in accordance with the applicable license. A development snapshot or an unfilled written-offer template is not a substitute for that release's source-distribution obligations.

This repository does not contain the complete HashStat cloud platform, installers, or system images. The licensing of a combined distribution must be assessed from the actual components and their integration; a separate process or a SaaS label alone does not settle that question.

The authoritative terms are in the applicable license texts, including [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html).
